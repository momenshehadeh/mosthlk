# 🧺 Mosthlk (مستهلك)
Your Trusted Fresh Grocery & Produce Store. Mosthlk is an online platform that offers a fast, reliable, and effortless online shopping experience for fresh fruits, vegetables, and daily groceries. We strive to provide top-quality farm-fresh produce with seamless order tracking and delivery straight to your doorstep.

# ⚡ Tech Stack & Languages

- **Primary Language:** JavaScript (98.5%)
- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Font Optimization:** [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) using the Geist font family.
